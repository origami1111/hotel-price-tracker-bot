# 🏨 Hotel Price Tracker Bot

Telegram-бот для отслеживания цен на отели с сайта [poehalisnami.ua](https://www.poehalisnami.ua/)

## 📋 Функциональность

- ✅ Добавление отелей для отслеживания
- ✅ Автоматическая проверка цен каждый час
- ✅ Уведомления об изменении цены
- ✅ Сохранение истории и данных пользователя
- ✅ Управление списком отслеживаемых отелей

## 🚀 Установка

### 1️⃣ Требования
- Python 3.10+
- pip

### 2️⃣ Получить токен Telegram бота

1. Напиши боту [@BotFather](https://t.me/botfather) в Telegram
2. Отправь команду `/newbot`
3. Следуй инструкциям (название бота, юзернейм)
4. Скопируй полученный токен (выглядит так: `123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11`)

### 3️⃣ Установить зависимости

```bash
pip install -r requirements.txt
```

### 4️⃣ Запустить бот

```bash
export TELEGRAM_BOT_TOKEN='твой_токен_здесь'
python hotel_price_tracker.py
```

**На Windows:**
```cmd
set TELEGRAM_BOT_TOKEN=твой_токен_здесь
python hotel_price_tracker.py
```

## 📱 Использование

### Основные команды

| Команда | Описание |
|---------|---------|
| `/start` | Начало работы |
| `/add_hotel <URL> <Название>` | Добавить отель для отслеживания |
| `/list_hotels` | Показать все отслеживаемые отели |
| `/remove_hotel <ID>` | Удалить отель из списка |
| `/help` | Справка по командам |

### Примеры

**Добавить отель:**
```
/add_hotel https://www.poehalisnami.ua/hotel/12345 "Отель Море"
```

**Удалить отель:**
```
/remove_hotel 0
```

## ⚙️ Как это работает

1. **Добавление отеля**: пользователь отправляет ссылку на страницу отеля
2. **Проверка цены**: бот получает начальную цену с сайта
3. **Сохранение**: данные сохраняются в файл `hotel_prices.json`
4. **Мониторинг**: каждый час бот проверяет цену
5. **Уведомление**: если цена изменилась, отправляется сообщение

## 🔧 Настройка парсера

Если бот не может получить цену, нужно адаптировать селектор CSS.

Для этого:

1. Открой сайт отеля в браузере
2. Нажми F12 (Инструменты разработчика)
3. Найди элемент с ценой (правой клик → "Посмотреть код")
4. Обнови селектор в функции `fetch_hotel_price()`:

```python
# Вместо этого:
price_elem = soup.find('div', {'class': 'price'})

# Напиши это (если класс другой):
price_elem = soup.find('span', {'class': 'hotel-price'})
```

## 🔒 Безопасность

- Данные пользователей сохраняются локально
- Используются HTTPS для всех запросов

## 🐛 Решение проблем

### Бот не отправляет сообщения
- Проверь, что ты написал боту `/start`
- Убедись, что токен скопирован правильно

### Цена не определяется
- Проверь ссылку в браузере
- Используй F12 для поиска элемента с ценой
- Обнови селектор в коде (см. раздел "Настройка парсера")

### ImportError при запуске
```bash
pip install -r requirements.txt --upgrade
```
